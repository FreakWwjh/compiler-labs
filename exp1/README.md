# 编译原理实验一 — DFA 模拟器

**运行环境**: openEuler aarch64 (鲲鹏开发板)  
**编译器**: g++ 10.3.1 (C++17)

## 项目结构

```
exp1/
├── README.md                 # 项目说明
├── Makefile                  # 编译脚本
├── dfa_simulator.cpp         # DFA 模拟器主程序
├── dfa_sim                   # 编译后的可执行文件
├── dfa_in1.dfa               # 示例 DFA（实验说明原例）
├── dfa_in2_binary.dfa        # 二进制 "以 11 结尾" DFA
├── dfa_in3_multi_accept.dfa  # 多接受状态测试 DFA
├── dfa_in4_space_alpha.dfa   # 多字符符号测试 DFA
└── 实验说明.md                # 原实验要求文档
```

## 功能特性

### 必做功能
1. **DFA 文件输入**：从 `.dfa` 文本文件读取五元组（字符集、状态集、开始状态、接受状态集、转移表）。
2. **DFA 校验**：
   - 开始状态唯一性、包含性检查
   - 接受状态集非空性、包含性检查
   - 转移表完整性检查
3. **规则字符串枚举**：输入最大长度 N，BFS 输出语言集中所有长度 ≤ N 的字符串。
4. **字符串判定**：模拟 DFA 逐步运行，逐字符显示状态转移，最终输出 Accepted / Rejected。

### 选做功能
1. **Git 版本控制**：项目已纳入 Git 管理，结构清晰。
2. **可视化增强**：
   - 终端内 ASCII 状态转移图输出
   - JSON 格式 DFA 导出（与实验二兼容）
3. **多字符符号支持**：字符集支持空格分隔的多字符符号（如 `+ - =`）。
4. **随机字符串生成**：支持按字符集随机生成字符串并判定。

## 编译与运行

```bash
cd ~/workspace/exp1
make clean && make
./dfa_sim [dfa_file.dfa]
```

默认加载 `dfa_in1.dfa`，也可指定其他 DFA 配置文件。

## DFA 文件格式

```text
ab          # 字符集（无空格则每个字符为符号；有空格按空格分隔）
4           # 状态数量
1           # 开始状态
4           # 接受状态集（空格分隔）
2 3         # 转移表：状态1 在 a→2, b→3
4 3         # 转移表：状态2 在 a→4, b→3
2 4         # 转移表：状态3 在 a→2, b→4
4 4         # 转移表：状态4 在 a→4, b→4
```

## 交互菜单

运行后进入交互菜单：
- `1` — 输出长度 ≤ N 的所有规则字符串
- `2` — 输入字符串并判定是否属于语言集
- `3` — 随机生成字符串并判定
- `4` — 可视化：ASCII 状态转移图
- `5` — 导出 DFA 为 JSON 格式
- `0` — 退出
